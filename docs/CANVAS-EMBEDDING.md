## Embed Example

Use a titled iframe and an adjacent direct link in the Canvas HTML editor:

```html
<iframe
  src="https://lapauzaiii.github.io/man3504-labs/labs/w9-inventory/"
  title="Week 9: Cowford Logistics Inventory Classroom Lab"
  width="100%"
  height="1400"
  style="border: 0;"
  loading="lazy"
></iframe>
<p><a href="https://lapauzaiii.github.io/man3504-labs/labs/w9-inventory/"
  target="_blank" rel="noopener">Open the Week 9 lab in a new tab</a></p>
```

Replace the URL and title for each resource. Preview as a student on desktop and mobile. The iframe has its own scrollable page; adjust height to suit the module. Keep the direct link for a larger workspace, printing, downloads or browsers that restrict embedded storage.

No student identifiers are needed. An ordinary iframe does not interpolate Canvas `$User.id` variables or create an LTI integration. Do not append student IDs for tracking.

## Student Work

Week 4 Cowford and Weeks 9–14 save locally when browser storage is permitted. JSON work files can be imported into the matching lab. CSV downloads contain classroom inputs only. Print produces the student's current work record; these labs contain no answer key or scoring engine.

Embedded storage may be unavailable or cleared between sessions. Export provides a portable record. Use a new-tab link if embedded downloads or printing are restricted. Nothing is uploaded to an instructor automatically.
