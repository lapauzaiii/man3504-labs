Excel Workbook Instructions

Your Netflix workbook should follow the Starbucks template structure.

  • Use the Data sheet in the Netflix starter file as your base data.
  • Create a new sheet named Forecasts.
  • Include controls for weighted moving average weights, the exponential smoothing alpha value, and the initial exponential smoothing forecast.
  • Build forecast columns for 3-year moving average, 3-term weighted moving average, and exponential smoothing.
  • Build error columns for Error, absolute error, squared error, and absolute percentage error.
  • Add summary cells for MAD, MSE, and MAPE.
  • Experiment with at least two weighted moving average weight sets and three alpha values.
  • Use the completed workbook results to answer the Canvas questions.

Helpful Canvas links: instructions and rubric page and assignment rubric.

Questions to Answer

Answer these items in Canvas using the results from your Excel file. The prompts are repeated here so you can keep working if Canvas is slow, but submit in Canvas whenever possible.

  1. Multiple choice: Which method is most likely to lag behind during a rapid revenue increase?
  2. True or false: The smoothing constant alpha in exponential smoothing must always be between 0 and 1.
  3. Multiple choice: Using Netflix data, calculate the 3-year moving average forecast for 2007 using the 2004, 2005, and 2006 actuals. The actuals are 2004 = 506.2, 2005 = 682.2, and 2006 = 996.7.
  4. Essay: Set up exponential smoothing with alpha = 0.30 and the first actual as the initial forecast. Paste or type your formula for the first row where exponential smoothing uses both the prior Actual and prior Forecast. In 1-2 sentences, explain how alpha = 0.30 affects responsiveness.
  5. Matching: Match each business goal to the accuracy measure: minimize average error size, heavily punish rare big misses, and express error as a percent for comparisons. Possible measures: MAPE, MSE, and MAD.
  6. Essay: From your Netflix workbook, identify which method and settings produced the lowest MAPE overall. Then explain whether you would recommend a stable or responsive forecast for Netflix and why in 2-3 sentences.
  7. File upload: Submit your completed Netflix Excel workbook. Only submit one XLS or XLSX file.
